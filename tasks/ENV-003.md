## Goal
Wind that scales with height, and gusts that always announce themselves 1.2 seconds in advance.

## Why
The gust tell is one of the game's real skills and one of its clearest fairness commitments. A gust with no tell is a bug, not a difficulty.

## Context
`gust_incoming()` is a promise: once it returns a value below the pre-roll time, the gust **will** happen. Never surprise the player. The audio is a rushing sound approaching across the rooftops; the visual fallback is screen-edge wind streaks. Both ship in this task.

## Interface
```gdscript
class_name Weather extends RefCounted
func step(dt: float, shift_fraction: float) -> void
func wind_at(height: float) -> float
func gust_now() -> float
func gust_incoming() -> float
func precipitation() -> String
```

## Acceptance
1. Wind follows the level's `windAtHeight` curve.
2. Every gust is preceded by `gust_incoming()` counting down through 1.2 s — asserted over 1,000 simulated gusts with zero exceptions.
3. The audio pre-roll and the screen-edge streak both fire from the same signal.
4. Gust intensity feeds `Wobble.amplitude_deg` and the nerve wind factor.
5. Deterministic for a given seed.

## Out of scope
Rain, the storm ramp and wet-grip are WEATH-001 at M2.
